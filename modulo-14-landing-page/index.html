Sobre o evento

O DevConnect 2026 é uma landing page criada para divulgar um evento fictício de tecnologia, programação e inovação. O projeto reúne informações sobre palestras, networking e experiências voltadas ao desenvolvimento profissional.

A página foi construída com Bootstrap, utilizando menu responsivo, classes utilitárias, seções organizadas e layout adaptado para diferentes telas.
